# Screenshots

The README's scope alignment table refers to the screenshots below. They are not generated: take each one from the live site (https://alufunders.nithaco.com) or a local run, and save it here as a PNG under the exact name given.

Before saving, make sure no real personal data is visible: emails, phone numbers, documents, or names of people who have not agreed. Use test accounts and the synthetic sample certificates in `server/samples/`.
